# Trademarks

The code is free software under the GNU AGPL v3 or later. The project's **name
and logo are not**: they identify the official releases and the hosted service,
and stay with the Maintainer.

## Fine without asking

- Saying your product works with, runs on, or is based on the project.
- Using the name to refer to the project in articles, talks, tutorials and
  package listings.
- Running an unmodified official release, for yourself or your clients, and
  saying so.

## Ask first

- Naming a fork, product, company or domain after the project, or with a name
  that can be confused with it.
- Offering a hosted service under the project's name.
- Using the logo in a way that suggests the Maintainer endorses you.

A fork is welcome. Please give it its own name and logo, and say it is based on
the project.

Questions: open an issue, or write to the Maintainer.
